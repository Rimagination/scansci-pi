# ScanSci 桌面端交付负面清单

> 目的：记录已经被用户指出或实际发生过的交付失误。以后只要命中任一条，均不得宣称“可用”“已完成”或交付给用户。

## 绝不能做

### 1. 功能与模型服务

- 不得把返回 `503`、鉴权失败、空响应或仅显示加载态的模型服务称为“已接通”。
- 不得只验证前端请求代码、Mock 或单元测试；必须用正式网关发起一次真实对话，并确认收到非空 assistant 回复。
- 不得把管理员尚未部署的服务端 Secret 误说成用户端配置问题。
- 不得把 API Key 写入 EXE、仓库、日志、设置文件、错误提示或截图；最终用户零配置不等于管理员无需一次性部署服务端 Secret。
- 不得声称“密钥录入窗口已打开/密钥已保存”，除非用户实际确认看到了窗口并且真实网关探测成功。
- 不得把未经 Windows PowerShell 5.1 实测的管理员脚本交给用户；脚本路径不得在 `param` 默认值阶段依赖尚未初始化的 `$PSScriptRoot`。

### 2. 对话交互

- 普通“通用”对话在尚未产生研究结果前，不得显示右侧“参考文献”栏；该栏只属于资料库问答、证据阅读或综述工作台。
- 不得只检查发送按钮样式；必须分别验收 Enter 发送和点击上箭头发送。
- 不得允许发送控件被透明层、禁用状态或错误的表单事件拦截。
- 对话失败时必须显示真实、可操作的错误状态，不得停在“正在生成回复”。

### 3. 桌面窗口与缩放

- Frameless 窗口不得把原生 `maximize()` 当作兜底；它可能覆盖 Windows 任务栏。
- 不得混用物理像素和逻辑像素。最大化必须以当前显示器工作区（排除任务栏）和当前窗口 DPI 换算后设置尺寸。
- 不得只在单一缩放比例验证窗口；至少人工检查 100%、125% 或 150% 中的实际目标环境。
- 不得把“进程已启动”当作桌面验收；需要确认窗口的实际 EXE 路径、界面版本和最大化后的任务栏可见性。

### 4. 构建、包与版本识别

- 不得用标题、图标或同名 `ScanSci.exe` 判断启动的是新版；必须核对运行进程的 `ExecutablePath` 和构建哈希/修改时间。
- 不得让新版与旧版复用会导致 Windows 重新激活旧程序的应用标识；若存在同名历史构建，验证包必须使用唯一 EXE 名称。
- 不得交付“文件夹存在”但 `ScanSci.exe` 缺失的包。
- 不得交付 0 字节、未校验或可能覆盖输出目录的压缩包。归档前后都必须确认其中含有 `ScanSci/ScanSci.exe`，且源 EXE 仍存在。
- 不得在构建仍运行、多个构建竞争同一 `dist` 目录，或旧 EXE 未经确认退出时发布结果。

### 5. 已确认的界面约束

- 不得重新引入首页中被移除的“快捷入口、任务与项目、个人与设置”提示。
- 模型选择器默认直接显示当前模型名（如 `GLM-4.7 Flash`），前方不加多余图标；发送按钮为黑色上箭头。
- 不得把任务与项目割裂展示；侧栏统一为“历史对话”，并支持折叠与搜索。
- 不得放任图标、文字、快捷键和下拉箭头不在同一视觉基线，或线宽明显不一致。
- 不得用凌乱的预览面板替代成品阅读界面；先检查信息层级、滚动、窄屏和空状态。

## 发布前必过清单

机器执行入口为 `scripts\release_gate.ps1`，流程和续跑方法见 `docs\release-workflow.zh.md`。没有最终状态为 `passed` 的 `release-report.json`，不得宣称发布完成。

| 验收项 | 最低证据 |
| --- | --- |
| 后端可用 | 正式网关真实请求返回非空 assistant 回复；记录 HTTP 状态和模型名，不记录密钥。 |
| 发送行为 | 在新启动的桌面包中，Enter 与点击发送各成功一次。 |
| 右侧面板 | 普通对话打开后右侧参考文献栏不可见；资料库问答有来源时才显示。 |
| 最大化 | 目标缩放下最大化后任务栏仍可见，恢复窗口位置与尺寸正确。 |
| 版本正确 | 记录运行进程 `ExecutablePath`；不得依赖同名旧包、窗口标题或图标。 |
| 包完整 | `ScanSci.exe` 存在；如提供 ZIP，ZIP 含该 EXE 且非 0 字节。 |
| 自动检查 | `python -m pytest tests\\test_desktop.py tests\\test_webapp.py tests\\test_llm.py tests\\test_app_settings.py -q` 通过；`node --check src\\scansci_html\\web\\app.js` 通过。 |
| 人工视觉 | 检查首页、对话页、最大化页至少各一张真实桌面截图，而非仅浏览器预览。 |

## 交付措辞规则

- 只有全部发布前必过项完成，才可以说“已可用”或“已交付”。
- 若服务端密钥、账号权限或真实 API 响应仍缺失，必须明确说“未完成”，并指出唯一缺少的管理员操作。
- 任何截图、单元测试或成功打包只能证明对应层级，不能替代真实端到端验收。
