对话

PaperQA2 类项目对 ScanSci 最值得吸收的是什么？

最值得吸收的是 notebook/source/chat 的产品组织，而不是把底层变成通用 RAG。 ScanSci 应保留 clean HTML/XML 与 evidence span 作为核心坐标，让回答、综述和导出都从可审计 evidence table 生成。

  1. 先组织来源。 Source 面板只放可信来源，并保留 HTML anchor、quote snapshot 与 citation audit。
  2. 再生成产物。 Studio 只能从 accepted 或 partial_support 证据生成摘要、矩阵和审阅集。
  3. 最后记录运行。 Codex 作为 control plane，本地小模型只做 action_decider，manifest 可复盘。
