## 本轮内容

- P0：UTF-8 检查、可重复的 SQLite schema 迁移与事务保护、文档/摘要/章节/证据片段/向量的明确计数语义。

- P2：稳定 document_id、内容哈希、摘要/章节/证据分层、增量索引、旧对话的知识库/index/evidence snapshot 继续追问。
- P3：独立联网学术搜索、零结果扩展、自动 Deep Research、证据问答/综述和真实引用定位。
- P4：可暂停/恢复/重试/取消的资源任务、系统 OCR/PaddleOCR/MinerU 语义化配置、六个正式 EasySlides 模板和统一 PPT 任务入口。

## 升级与回滚

1. 关闭 ScanSci，保留现有 workspace/evidence 数据库；升级前复制数据库和配置文件。
2. 启动候选包并继续使用原来的数据路径。schema 迁移在事务中执行，可重复；知识库迁移采用惰性兼容路径，不触发全量向量重建。
3. 升级后检查文档、摘要、章节、证据片段和向量计数，并用旧对话继续追问确认绑定的知识库、索引版本和 evidence snapshot 仍在。
4. 如需回滚，关闭候选包，改用上一版本便携目录；不要删除新数据。若数据库迁移本身需要回退，在应用关闭后从升级前备份恢复 workspace/evidence 数据库，再启动上一版本。

本轮 F 盘真实用户库迁移前后计数保持不变：`376/376/9944/151494/151494` 与 `420/420/11048/191568/191568`（文档/摘要/章节/证据片段/向量）；空默认库为 `0/0/0/0/0`。
