# ScanSci 0.2.1 热修复说明

发布日期：2026-08-03

## 修复内容

- 修复“组件下载任务”被错误识别为论文检索任务的问题。
- 询问失败、卡住或正在运行的本地任务时，ScanSci 现在直接读取本机任务记录，说明失败组件、模型、文件、下载来源、原因和重试位置。
- 模型文件改为经过验证的分段下载；HTML、JSON、XML、错误页和截断响应不会再写入模型文件。
- 断点续传只复用带校验元数据的片段；旧版遗留的无效临时文件会被安全丢弃后重新下载。
- 多模型资源任务分别显示整组完成度与当前模型进度，避免“50% / 18 KB / 285 MB/s”这类互相矛盾的提示。

## 安装与重试

安装 `ScanSci-0.2.1-windows-x64-setup.exe` 后，进入“设置 → 资源配置 → 下载任务”，对失败的“研究检索组件”点击“重试”。程序会自动忽略旧版留下的未经校验片段。

ScanSci core 安装包仍保持轻量，不包含 PyTorch、Transformers、sentence-transformers 或本地模型权重；这些资源继续由用户按需安装。

## 校验重点

- 精确问题“现在有一个失败的组件下载任务，你知道是什么吗”必须由本机状态回答处理，不启动学术搜索。
- ModelScope 官方模型清单和 Range 响应已经过真实小范围请求验证。
- 下载器拒绝伪装成 `.safetensors` 的错误响应，并在失败时不留下可被误认为有效模型的临时文件。
