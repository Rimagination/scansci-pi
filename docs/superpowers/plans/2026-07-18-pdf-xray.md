# PDF X-Ray Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a globally discoverable `pdf-xray` skill that produces evidence-backed vector/raster/mixed/uncertain PDF classifications.

**Architecture:** Keep the skill concise and put deterministic inspection in a Python CLI. The CLI recursively parses PDF resource trees with `pypdf`; it uses PyMuPDF only for displayed-object geometry. Page labels use raw paint/text/image evidence, and region labels use overlap with displayed image/vector bounds.

**Tech Stack:** Python 3, `pypdf`, PyMuPDF (`fitz`), `pytest`, and Pillow for generated test fixtures.

```python
import json
import subprocess
import sys
from pathlib import Path

import fitz
import pytest
from PIL import Image


SKILL_ROOT = Path(__file__).resolve().parents[1]
SCRIPT = SKILL_ROOT / "scripts" / "audit_pdf.py"


def write_pdf(path: Path, mode: str) -> None:
    png = path.with_suffix(".png")
    Image.new("RGB", (40, 40), "#e85d04").save(png)
    if mode == "vector-form":
        source = fitz.open()
        source_page = source.new_page(width=612, height=792)
        source_page.draw_rect(fitz.Rect(80, 80, 240, 200), color=(0, 0.37, 0.45), width=3)
        source_page.draw_line(fitz.Point(80, 80), fitz.Point(240, 200), color=(0, 0.37, 0.45), width=3)
        pdf = fitz.open()
        page = pdf.new_page(width=612, height=792)
        page.show_pdf_page(fitz.Rect(0, 0, 612, 792), source, 0)
        pdf.save(path)
        pdf.close()
        source.close()
        return
    pdf = fitz.open()
    page = pdf.new_page(width=612, height=792)
    if mode in {"raster", "mixed"}:
        page.insert_image(fitz.Rect(72, 500, 252, 680), filename=str(png))
    if mode == "mixed":
        page.draw_line(fitz.Point(350, 100), fitz.Point(500, 100), color=(0, 0.37, 0.45), width=3)
    pdf.save(path)
    pdf.close()


def run_cli(pdf: Path, *args: str) -> dict:
    completed = subprocess.run(
        [sys.executable, str(SCRIPT), str(pdf), *args],
        text=True,
        capture_output=True,
        check=True,
    )
    return json.loads(completed.stdout)


@pytest.fixture()
def samples(tmp_path: Path) -> dict[str, Path]:
    paths = {name: tmp_path / f"{name}.pdf" for name in ("raster", "mixed", "vector-form")}
    for name, path in paths.items():
        write_pdf(path, name)
    paths["malformed"] = tmp_path / "malformed.pdf"
    paths["malformed"].write_text("not a pdf", encoding="utf-8")
    return paths


def test_classifies_a_displayed_image_without_vector_paint_as_raster(samples: dict[str, Path]) -> None:
    result = run_cli(samples["raster"])
    page = result["pages"][0]
    assert page["classification"] == "raster"
    assert len(page["evidence"]["visible_images"]) == 1
    assert page["evidence"]["paint_operations"] == 0


def test_recurses_into_a_form_xobject_for_vector_evidence(samples: dict[str, Path]) -> None:
    result = run_cli(samples["vector-form"])
    page = result["pages"][0]
    assert page["classification"] == "vector"
    assert page["evidence"]["form_xobjects"] >= 1
    assert page["evidence"]["paint_operations"] >= 1


def test_labels_an_image_and_a_distant_line_as_mixed_at_page_level(samples: dict[str, Path]) -> None:
    result = run_cli(samples["mixed"])
    assert result["pages"][0]["classification"] == "mixed"


def test_region_uses_displayed_geometry_instead_of_the_page_label(samples: dict[str, Path]) -> None:
    result = run_cli(samples["mixed"], "--region", "1:60,480,270,690")
    assert result["pages"][0]["region"]["classification"] == "raster"


def test_malformed_pdf_is_reported_as_uncertain(samples: dict[str, Path]) -> None:
    result = run_cli(samples["malformed"])
    assert result["document_warnings"]
    assert result["pages"] == []
```

**Files:**

- [ ] **Step 1: Implement the CLI contract.**

Expose:

```text
python audit_pdf.py INPUT.pdf [--region PAGE:X0,Y0,X1,Y1]
```

Return stdout JSON with this stable shape:

```json
{
  "source": "INPUT.pdf",
  "document_warnings": [],
  "pages": [
    {
      "page": 1,
      "classification": "vector",
      "confidence": "high",
      "evidence": {
        "raw_images": [],
        "visible_images": [],
        "form_xobjects": 1,
        "paint_operations": 2,
        "text_show_operations": 0,
        "vector_drawing_boxes": []
      },
      "warnings": []
    }
  ]
}
```

- [ ] **Step 2: Implement recursive resource and content-stream traversal.**

Use `pypdf.generic.ContentStream`; recurse into each `/Form` object's `/Resources`; protect both resource and stream traversal with indirect-object identity sets. Record `/Image` metadata (`/Width`, `/Height`, `/BitsPerComponent`, `/Filter`, `/SMask`, `/Mask`) separately from Form counts. Count only `S`, `s`, `f`, `F`, `f*`, `B`, `B*`, `b`, `b*`, and `sh` as paint operations. Count `Tj` and `TJ` as text-show operations but never count `m`, `l`, `re`, `W`, or `n` as vector-paint proof.

- [ ] **Step 3: Add displayed-object geometry and classification.**

Use `page.get_image_info(xrefs=True)` for visible image bounding boxes and `page.get_drawings()` for vector-drawing bounding boxes. Classify a page as `mixed` when it contains a displayed image plus either raw paint or text-show evidence; classify it as `raster` when it contains a displayed image and neither; classify it as `vector` when it contains raw paint or text evidence without a displayed image; otherwise classify it as `uncertain`. Return a `region` object only for the page selected by `--region`; classify its overlap evidence independently, and use `uncertain` when no displayed image or drawing intersects the supplied rectangle.

- [ ] **Step 4: Keep malformed PDFs machine-readable.**

Catch open/decrypt/parse errors at the document boundary and emit:

```json
{
  "source": "INPUT.pdf",
  "document_warnings": ["Could not open PDF: ..."],
  "pages": []
}
```

Exit with code `0` for this outcome so batch analysis can retain uncertain documents.
