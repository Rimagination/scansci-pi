# 设置页视觉系统统一与全局字号联动实施计划

## 目标

- 让所有设置页共用同一套字体、字号、颜色语义变量，并以常规页作为视觉基准。
- 让常规设置中的“界面字号”作用于整个应用界面，而不只影响设置页局部文本。
- 将“关于搜索科学”改为左侧导航中的“软件更新”页面。
- 移除设置内容中不必要的横向分隔线，同时保留必要的控件轮廓和可读层级。

## 实施步骤

1. 在现有 Web 回归测试中加入全局字号、设置页共享视觉变量、无分隔线和软件更新导航的失败断言。
2. 梳理 `app.js` 的字号偏好应用路径，补齐根节点字号缩放变量/应用壳缩放，并更新软件更新页面文案与导航标签。
3. 在 `styles.css` 末尾增加统一设置视觉系统覆盖层：字体、字号、语义颜色、卡片与行间距、深色主题映射，以及去除设置内容分隔线。
4. 运行针对性测试、JavaScript 语法检查和差异检查，打开常规页、默认能力页、本地模型页与软件更新页预览，核对浅色/深色及字号缩放。

## 验收

- 设置页控件和正文均继承 `var(--ui)` 与语义颜色变量。
- 切换界面字号后应用主界面和设置页同步缩放。
- 左侧显示“软件更新”，点击后页面标题和内容均为更新管理语义。
- 设置内容没有装饰性横向分隔线，浅色/深色均保持清晰层级。
