# ScanSci Research Agent 产品设计

日期：2026-07-18

## 产品判断

ScanSci 不应成为“另一个聊天框”，也不应照搬 NotebookLM。它的核心产品是一个以可追溯证据为底座、能调用科研工具并交付研究产物的桌面 Agent。

这次设计融合四类产品语言：

- 玻尔：科研场景入口、学术发现、引用可见的回答与专业工具导航。
- NotebookLM：同一个资料项目中的 Sources / Chat / Studio 关系，以及所有产物共享一份来源底座。
- QoderWork / Codex：任务优先、工作目录、模型切换、技能、MCP、插件与可扩展执行环境。
- ScanSci：句子级证据、原文锚点、引文审计，以及 Journal Scout、Citation Lab、Paper Atlas、scansci-pdf、EasySlides 等现有能力。

## 体验原则

1. **首页只做一件事**：开始研究任务。工具不在首页展开解释。
2. **项目是上下文**：资料、证据、对话、综述和 PPT 属于同一个研究项目。
3. **模式是交付物**：综述、图谱、引文核查、文献下载和 PPT 都有独立工作区。
4. **证据始终可回跳**：结论、综述段落和演示页最终都应定位到来源、原句或 DOI。
5. **状态必须诚实**：区分已连接、缺少密钥、需要资料、未检测到运行时和任务失败。
6. **少配置**：常用 API 供应商预填协议、Base URL 和模型；用户主要填写密钥。

## 信息架构

```text
ScanSci
├─ 新建研究（任务输入、项目、当前对话模型）
├─ 资料库（当前项目来源）
├─ 研究工具
│  ├─ 期刊查询 / Journal Scout
│  ├─ 引文核查 / Citation Lab
│  ├─ 研究图谱 / Paper Atlas
│  └─ 文献下载 / scansci-pdf
├─ 文献综述（问题 → 证据矩阵 → 写作 → 核验）
├─ PPT Studio（大纲 → EasySlides 项目 → 可编辑 PPTX）
└─ 设置
   ├─ API 模型
   ├─ 本地模型
   ├─ 模型路由
   ├─ 技能
   ├─ MCP 服务器
   └─ 插件
```

## 模型架构

API 模型和本地模型不是同一种配置的两个入口。

| 任务角色 | 默认取向 | 说明 |
|---|---|---|
| 推理 | API | 研究规划、证据比较、判断与工具编排 |
| 写作 | API | 问答、综述、长文与语言组织 |
| 检索 | 本地 | 私有资料召回，降低成本并保护数据 |
| 嵌入 | 本地 | 建立语义索引 |
| 重排 | 本地 | 精排候选证据 |
| 视觉 | 可指定 | 图表、扫描页与视觉证据理解 |
| 演示 | API 或专用模型 | 叙事结构、页级规划与讲述节奏 |

主页的模型选择是当前任务的显式模型；“模型路由”定义 Agent 后台各阶段的默认模型。用户可以统一管理，也可以逐任务覆盖。

## Agent 执行合同

一个研究任务按以下状态推进：

1. 识别意图与交付物。
2. 检查当前资料和工具可用性。
3. 形成可见计划。
4. 调用检索、下载、期刊、引文、图谱或演示工具。
5. 生成带证据引用的中间结果。
6. 执行引用与元数据核验。
7. 交付回答、综述、证据矩阵或 PPT 项目。

所有工具调用应返回结构化状态；失败不能伪装成成功，也不能只显示泛化的“网络错误”。

## 本次已落地

- 简洁白色的任务首页和悬浮式中心输入框。
- 独立资料库、研究工具、综述、Paper Atlas、下载、期刊、引文核查和 PPT 模式。
- OpenAI、Anthropic、Gemini、DeepSeek、阿里云百炼和 OpenRouter 预设。
- Ollama、LM Studio、llama.cpp 与内置证据引擎的统一管理。
- 推理、写作、检索、嵌入、重排、视觉、演示的模型路由。
- API 密钥进入系统凭据管理器；配置文件保持脱敏。
- 连接测试以及 API 模型在实际问答链路中的生效。
- Journal Scout、Citation Lab、Paper Atlas、scansci-pdf 和 EasySlides 后端接入。
- 有来源绑定的 PPT 大纲与 EasySlides 项目初始化。

## 后续产品阶段

### P1：可用的科研 Agent

- 工具调用时间线与可取消任务。
- 资料导入、批量 DOI / PDF 下载并自动入库。
- 综述证据矩阵、主题聚类和段落级引用编辑。
- 本地模型自动发现与模型列表同步。

### P2：Studio 交付物

- PPT 页级编辑器、模板选择、SVG 渲染与 PPTX 导出。
- 表格、研究时间线、方法比较、概念图和数据摘要。
- 每一页的证据抽屉和引用页自动生成。

### P3：开放生态

- MCP 进程生命周期和权限确认。
- 技能清单、参数表单和运行记录。
- 插件签名、来源审查、安装与更新。
- 多 Agent 角色：检索员、证据审计员、综述作者和演示设计师。
