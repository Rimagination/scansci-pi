# Nature Paper to PPT

Convert the paper's argument, not its page count.

1. Identify audience, duration, language, presentation goal, and the paper's central question.
2. Build a story spine: context, question, approach, key findings, interpretation, limitations, and take-home message.
3. Give each slide one claim-bearing title and one visual job. Use figures, comparisons, process diagrams, or result cards only when supported by the source.
4. Preserve figure numbering, panel labels, captions, statistics, units, and source-page or evidence anchors. Mark adapted redraws as adapted.
5. Put methods and limitations where the audience needs them; do not turn the evidence-verification process into the presentation story.
6. Return a slide plan before creating a PPTX. Use ScanSci's presentation tools and selected templates only after the user requests artifact creation.

Do not invent a result, simplify a branch into a linear sequence, or imply causality that the paper does not support. Keep a final references slide and a speaker-note source map when possible.

This is a ScanSci adaptation of the `nature-paper2ppt` workflow from Yuan1z0825/nature-skills and the existing ScanSci `scientific-slides` contract.
