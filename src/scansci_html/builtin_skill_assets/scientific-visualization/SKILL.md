# Scientific Visualization

Preserve scientific meaning before optimizing appearance.

1. State the data, transformation, comparison, audience, destination, and intended inference.
2. Keep raw data, exclusions, missing-value codes, analysis code, normalization, binning, image adjustments, and random seeds traceable.
3. Choose encodings that match the variable types and uncertainty. Use labels, units, legends, accessible colors, and redundant cues; avoid decorative distortion and unexplained dual axes.
4. Keep static, interactive, and machine-readable deliverables distinct. Provide a data table or accessible fallback when needed.
5. Inspect the rendered output at the actual delivery size and audit captions, annotations, source references, and numerical consistency.

Never hide inconvenient observations, connect missing points without justification, or claim that DPI, a palette, or an automated export makes a figure journal-compliant. Verify the target journal and article type before applying venue-specific rules.
