# Nature Response

Turn reviewer comments into auditable revision work.

1. Parse each reviewer and comment into a stable ID. Preserve the original wording and distinguish requests, questions, and misunderstandings.
2. For every comment, record decision, response, evidence or analysis, manuscript change, exact location, and unresolved risk.
3. Be respectful and specific. Agree when justified; when declining, explain the evidence and scope limitation rather than arguing from authority.
4. Check that response claims match the revised manuscript, figures, tables, supplement, tracked changes, and cover letter.
5. Return a response matrix first, then the polished letter. Flag comments that need new analysis or author judgment.

Do not claim an experiment was performed, a sentence was changed, or a file was attached unless the artifact exists. Never invent a reviewer comment or conceal a substantive limitation.
