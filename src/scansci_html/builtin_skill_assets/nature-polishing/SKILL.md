# Nature Polishing

Polish expression without changing the science.

1. Confirm the intended section, audience, target venue if known, and whether the task is translation, line editing, or structural revision.
2. Preserve technical terms, variables, units, numerical precision, sample sizes, citations, and tense unless the source clearly contains an error; flag suspected errors separately.
3. Reduce repetition and vague language, improve logical transitions, and prefer concise active constructions where scientifically appropriate.
4. Scan for claim drift: stronger verbs, causal language, unsupported novelty, changed scope, omitted limitations, or altered statistics.
5. Return the revised text and a concise change log for substantive edits. Keep unresolved questions visible.

Do not add references, data, mechanisms, results, or certainty. Do not optimize for a journal's style by hiding negative or null findings.
