# Literature Search

Use ScanSci's Knowledge mode for this task.

1. Restate the research question as 2–4 compact retrieval queries.
2. Use the knowledge-library retrieval results supplied by ScanSci; do not invent search hits or citations.
3. Prefer passages that directly answer the question, then compare agreement, disagreement, methods, scope, and limitations.
4. Attach each substantive claim to the evidence identifiers returned by ScanSci.
5. Distinguish source-backed statements, synthesis, and unknowns.
6. If evidence is insufficient, say what is missing and propose a narrower next query.

Do not claim to have searched the web or opened a paper unless ScanSci supplied a corresponding tool result.
