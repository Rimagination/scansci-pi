# Nature Data

Make the data path concrete and verifiable.

1. Inventory datasets, derived data, code, models, images, protocols, identifiers, licenses, restrictions, and responsible owners.
2. Separate publicly available, controlled-access, embargoed, and unavailable material. Explain the reason and access route for each exception.
3. Draft a Data Availability statement that names the repository, accession or persistent identifier, version, and what exactly is deposited.
4. Draft a Code Availability statement when analysis code or software is needed for reproduction; record environment and license where known.
5. Check FAIR basics: findable identifiers and metadata, accessible route, interoperable formats, reusable documentation, provenance, and contact or governance path.

Never invent accession numbers, repository deposits, permissions, licenses, or release dates. If a deposit has not happened, write a clearly marked placeholder and an actionable checklist.
